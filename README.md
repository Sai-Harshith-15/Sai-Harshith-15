## What I do

- **Mobile:** Flutter apps with BLoC and clean architecture, Firebase, push notifications, maps and admin dashboards.
- **Backend:** FastAPI, Django REST Framework, Node.js with Express and NestJS, on PostgreSQL and MongoDB.
- **Web:** React, Next.js and TypeScript with Tailwind.
- **AI and agents:** RAG pipelines, multi-agent systems with LangGraph, LangChain and CrewAI, plus machine learning and deep learning.
- **Agent engineering:** harness, prompt and context engineering, so agents work reliably on real codebases.
- **Cloud and delivery:** AWS, Docker, Podman and CI/CD, with linting, type checks and security scans before I call work done.

## Working principles

- Prove it with a command: tests, linters, type checks and scanners decide when work is done.
- Security is part of the build: secrets scanning, ownership checks on every object route, and no placeholder data presented as real.
- Agents need good context: clear instructions, the right tools and an outside check on their output.
- Small, readable commits.
